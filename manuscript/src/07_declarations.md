# Declarations

## Data availability

All data used in this study are public. The wind data are from the ERA5
reanalysis of the Copernicus Climate Change Service (Hersbach et al., 2020;
dataset doi:10.24381/cds.adbb2d47), obtained through the Open-Meteo
historical-weather service (Zippenfenig, 2023). The hourly input series for
the three grid nodes, the earlier series downloaded from the Copernicus
Climate Data Store that was used as an input check, and every result file
are stored in the project repository together with their SHA-256 checksums
and retrieval records. The Open-Meteo series is a redistribution of ERA5 and
is not bit-identical to a download from the Climate Data Store. The Global
Wind Atlas 4.0 layer, the EMODnet Digital Bathymetry DTM 2024 (EMODnet
Bathymetry Consortium, 2024) and the official documents cited (the candidate
area notice and polygon, the draft specification, the decree defining the
protected area, and the grid emission-factor form) are available from their
publishers; the extracts used here are stored in the repository. This paper
contains modified Copernicus Climate Change Service information; neither the
European Commission nor ECMWF is responsible for any use that may be made of
it.

## Code availability

The analysis is fully scripted in Python. One command regenerates all result
files from the stored inputs, a second generates the text of this manuscript
and all tables from those result files, and an automated test suite checks
the consistency of inputs, results, text and tables. A clean checkout
reproduces the result files byte for byte. The code is stored in the same
repository as the data.
