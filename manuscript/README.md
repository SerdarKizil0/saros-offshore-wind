# Manuscript sources

| File | Status |
|---|---|
| `src/00_abstract.md` … `src/09_figures.md` | **Edit these.** Prose sources of the whole manuscript: title, abstract and keywords (00); Sections 1 to 6 (01–06); declarations (07); working reference list (08); figure captions (09). Numbers are placeholders of the form `{{file:key.path\|format}}` that point into `results/revised/` |
| `00_abstract.md` … `09_figures.md` | Generated from `src/` by `scripts/11_build_manuscript_sections.py`. Do not edit |
| `tables.md`, `supplementary_tables.md` | Generated by the same script from `results/revised/`. Do not edit |
| `../figures/revised/fig1_site_map` … `fig4_sensitivity_categories` (`.pdf`, `.svg`, `.png`) | Publication figures, generated by `scripts/12_build_figures.py` from `results/revised/` (and, for the map, the documented geographic inputs). `09_figures.md` links each caption to its file; the build stops if a linked figure is missing |
| `FIGURE_BRIEFS.md`, `medium_yazisi.md`, `REFERENCES_VERIFIED.md` | Earlier working material; not part of the revised manuscript and partly superseded. Do not publish before revision |

Rebuild and check:

```bash
python scripts/12_build_figures.py                      # regenerate the figures
python scripts/12_build_figures.py --check              # compare committed figures by content
python scripts/11_build_manuscript_sections.py          # write the generated text files
python scripts/11_build_manuscript_sections.py --check  # verify they are up to date
python -m pytest -q tests/test_manuscript_5b1.py tests/test_manuscript_5b2.py \
    tests/test_figures_5c1.py tests/test_fig1_site_map.py
```
